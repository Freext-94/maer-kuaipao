# 马儿快跑 · 品牌素材（示例）

这些文件都是**示例素材**，上线前按同名文件替换即可，不需要改代码。

当前示例方向：**卡通马形象**（圆润、亲切、有速度感），不是写实赛马。最终 logo 由设计替换时，建议保留「大脑袋 + 长脸 + 小耳朵 + 鬃毛」这几个识别点，确保缩到 32px 仍能看出是马。

## 固定文件名与用途

| 文件 | 用途 | 建议尺寸 | 要求 |
|---|---|---|---|
| `logo-horizontal.svg` | 侧边栏、登录页、文档抬头 | 360×96 | 透明底，左右留白 ≥ 8px |
| `logo-mark.svg` | 头像、手机端、favicon 大图 | 128×128 | 透明底，圆角可自带 |
| `logo-vertical.svg` | 启动页、海报 | 240×240 | 透明底 |
| `favicon.svg` | 浏览器标签 | 64×64 | 简版，别放小字 |
| `login-hero.svg` | 登录页右侧插画 | 960×720 | 深色底也可，注意文字对比 |
| `empty-orders.svg` | 空订单/空看板 | 480×320 | 浅底，留白多 |
| `empty-debts.svg` | 空欠款 | 480×320 | 浅底，留白多 |
| `service-buy.svg` | 代买跑腿图标 | 96×96 | 圆角方形底 |
| `service-pickup.svg` | 代取送图标 | 96×96 | 圆角方形底 |
| `service-errand.svg` | 代办图标 | 96×96 | 圆角方形底 |
| `service-transfer.svg` | 接送图标 | 96×96 | 圆角方形底 |

## 品牌色（示例）

- 主色 `#0F766E`（青绿，稳）
- 强调色 `#F59E0B`（琥珀，快）
- 墨色 `#0F172A`
- 背景 `#F5F7F9`

## 替换方式

1. 设计与导出同名文件（SVG 优先；位图用 2x/3x）。
2. 覆盖 `prototype-v2/assets/brand/` 下同名文件，刷新页面即可。
3. 正式前端上线时，把同一套文件放到 `frontend/public/brand/`，路径保持 `/brand/xxx.svg`。
4. 若文件名必须变，改 `frontend/src/brand.js` 里的映射，不要在页面里散落写死路径。

## 注意

- 不要在 logo 里写"示例"字样；示例标识由页面上的「示例素材」标签承担。
- 深色侧边栏上用的是反白 logo；如果最终 logo 只有深色版，请同时提供 `logo-horizontal-light.svg`。
- favicon 不要用带细字的横版，手机桌面会糊。
