# 马儿快跑 · 改造后可点原型 v2

这是按 2026-11-21 新决策重做的**纯静态可点原型**，不是生产代码。

## 怎么打开

- 直接双击 `index.html`（推荐 Chrome / Edge）。
- 或在本目录起一个静态服务：

```bash
python -m http.server 8899
# 打开 http://127.0.0.1:8899/index.html
```

数据存在浏览器 `localStorage`，点右上/侧边栏「重置演示数据」可恢复。

## 这一版重点验证的交互

- 电话录单：客户/商家输入即搜、旁边内联新建；新客只填姓名/手机/备注；5 个常用词点击追加；多图/音频附件；跑腿费默认 10 元；5 类服务动态表单。
- 取货：默认「扫码支付」，现金备选；小票照片不传也能提交。
- 订单详情：金额账单化，逐笔看货款/服务费/调整/已收/未收；可打印。
- 欠款：没有账期、额度、超额拦截；只记录、查询、登记还款、复制/打印催缴。
- 账号：商家/骑手/客户登录；多角色工作区切换；超管权限矩阵；受限管理员被拦。
- 品牌：卡通马示例素材，固定文件名，上线后同名替换；单号前缀 `MR` 可在设置改。

## 自动验证过的主链路

用 Playwright 跑过：

1. 老板登录 → 电话录单（检索客户/商家、常用词、附件、默认 10 元、指派）。
2. 取货（默认扫码、不传小票）→ 结单只收一半 → 欠款页出现。
3. 内联新建客户 + 内联新建商家 → 建单成功。
4. 商家登录 → 待备货 → 备货完成。
5. 骑手登录 → 确认取件。
6. 客户登录 → 代办下单。
7. 受限管理员进用户页被拦；超管授权后可进。
8. 设置改单号前缀 `MR2` → 新单号生效。
9. 常用词新增/删除按钮可用。

## 品牌素材

全部在 `assets/brand/`，都是**示例素材**。上线后按同名文件替换即可，不用改代码。尺寸、用途、深色版要求见 `assets/brand/README.md` 和 `brand.html`。

当前方向：**卡通马形象**——圆脑袋、长脸、小耳朵、琥珀色鬃毛，带速度线；不是写实赛马，也不是「马」字。

## 与正式代码的边界

- 本目录只有 HTML/CSS/JS，无后端、无数据库、无真实支付。
- 正式改造按 `../docs/需求与改造计划.md` 的 B0–B4 批次落地；原型只用于评审交互和边界。
- 所有金额为演示数据，不构成真实账单。
