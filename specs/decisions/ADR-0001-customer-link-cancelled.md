# ADR-0001 取消客户专属下单链接（替代原"保留链接"决策）

## 背景
V6 曾新增 `t_customer_link` 与 `PublicCustomerLinkController`，提供客户免登下单/查单链接。后续业务口径调整：不再提供该免登入口，客户自助下单使用登录态 `/api/c/orders`；商家端也只保留工作台，不再代客下单。

## 决策
取消客户专属链接功能，删除相关接口、前端页面、`t_customer_link` 表与 `link.manage` 权限（V9）。商家端代下及其仅服务于代下表单的辅助接口一并删除。

## 后果
- `ADR-0001` 原"保留受限链接"决策作废，以本文件为准；
- 客户仍需通过 `/api/c` 登录态进入，管理员可在用户与权限中维护客户账号；
- 商家只查看自己参与的单，不能代客录单；需要录单时由调度台或骑手端完成；
- 账单页仍负责收款、欠款、减免与还款申报核对，订单抽屉不再提供登记收款。
