# ADR-0006 迭代 2026-11-23 需求变更

## 背景
用户提出以下变更：
1. 烟酒类目 code 改为英文短码、name 保持中文「烟酒」（2026-11-24 修正）
2. 超市生鲜拆分为超市 + 生鲜
3. 新增蛋糕店、咖啡厅、奶茶店类目
4. 用户信息支持单行地址编辑；客户客户端仅可维护地址+电话，不可改名，不显示备注
5. 订单 source 由 source_channel 自动判定

## 决策
- 商家类目种子更新（V12/V16 迁移）：烟酒类目 name 保持「烟酒」、code 为英文 `tobacco_alcohol`；新增 4 个类目
- t_user 新增 address VARCHAR(255) 单行地址字段
- 客户端编辑表单仅展示 address + phone，name 只读，remark 隐藏
- OrderService.create 中 source 由 source_channel 推导

## 后果
- 需 Flyway V9/V12/V16 迁移
- 需更新 UserController、CustomerView、OrderService
- 需更新 specs/data-model.md、domain.md、api.md、acceptance.md
